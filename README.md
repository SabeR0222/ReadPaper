# ReadPaper · 端侧具身智能文献库

面向端侧具身智能部署研究的 VLA / WAM 文献探索网站，用于查找论文、比较加速方法，并整理自己的阅读记录。

收录方向包括模型设计、量化、剪枝、蒸馏、编译与运行时优化、动作解码和异步调度等。论文信息以原始论文页面为核验入口；预印本与会议、期刊论文应结合其发表状态分别判断。

## 功能

- 按 VLA / WAM、论文类型、模型、硬件、年份、发表场所及研究团队筛选。
- 搜索论文标题、作者、模型、编号和加速方法。
- 查看关键贡献、原文链接及论文报告的部署指标与测量口径。
- 添加、修改、删除文章，编辑标签及其他元数据。
- 导出 JSON 备份，或导入 JSON 合并文献记录。
- 添加、修改、删除和导入操作均需逐次验证编辑密钥，启用后端后直接形成 Git 提交。

## 使用与数据同步

文献的正式数据源为仓库中的 `papers.json`。启用同步后端后，添加、修改、删除和导入会直接提交到 GitHub；每次提交可在仓库历史中查看和恢复。其他设备点击“刷新文献”即可读取最新记录。

**首次启用仍需部署后端并配置服务器凭证。** 在 `config.js` 的 `apiBase` 为空时，网站只读取 `papers.json`，编辑操作会提示“后端尚未配置”，不会假装保存成功。

完整操作步骤见 [后端部署与配置说明](docs/backend-setup.md)。GitHub 凭证只存于服务器 Secret；网站编辑密钥也由后端验证。

- 查询、搜索、筛选不产生 Git 提交。
- 保存失败或版本冲突时不会更新共享数据的本地显示；请核对后再重试。
- JSON 可用于备份和迁移，导入将合并到共享库，同 ID 记录以导入文件为准。
- 旧版浏览器记录不会自动覆盖共享库；如页面显示“导出旧浏览器记录”，请先导出并核对，再通过导入提交。
- `data.js` 保留为旧版数据参考，新版本不再加载它；请更新 `papers.json`。

## 论文与指标说明

本库是人工精选的研究起点，并非穷尽性系统综述。论文的发表状态、作者单位和实验结果应以原论文及正式会议、期刊页面为准。

硬件标签表示论文报告的实验范围，不代表所有设备均已验证。比较延迟、加速倍数、显存与任务表现时，请同时检查模型规模、任务、批量、精度和硬件条件；不同实验条件下的数值不宜直接排名。
